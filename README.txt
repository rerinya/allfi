Steps to start the project using virtual environments:
1. In the PyCharm project, go to File -> Settings -> Project Interpreter, and configure the Virtualenv Environment by selecting the python.exe file from the created environment, or if using vscode, you can create a new environment using command like python -m venv venv
2. Install the dependencies with: pip install -r requirements.txt
3. In the terminal, enter: cd mysite
4. In the terminal, enter: python manage.py runserver
